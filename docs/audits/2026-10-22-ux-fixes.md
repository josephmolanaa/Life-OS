Perbaikan tambahan:

- Query finance gagal tidak lagi berubah menjadi array kosong/saldo nol; error boundary menyediakan coba lagi.
- Mode privasi juga menyembunyikan nominal pada daftar/ringkasan transaksi.
- Reset harian mengikuti zona waktu browser yang tervalidasi; completion bersamaan tidak tertimpa; edit nama tidak memperpanjang completion kemarin.
- Validasi tanggal Discipline bekerja di UTC+7/UTC-7; tanggal kemarin dan kalender palsu ditolak.
- Kode mata uang divalidasi; tanggal query invalid tidak menyebabkan crash; edit mempertahankan wallet arsip.
- Kegagalan jaringan login/profil bisa dipulihkan; URL avatar dibatasi HTTP/HTTPS.
- Penghapusan tugas dashboard meminta konfirmasi; cadangan browser hanya ditawarkan jika memang ada.
- Teks kartu dashboard membungkus agar informasi tidak terpotong.

## Verifikasi

- Production build + pemeriksaan TypeScript lulus; ESLint seluruh proyek lulus.
- 16 check lokal lulus: amount-input, local-date, local-todos, diary, physique-errors, activity-discipline, daily-quests, daily-rollover, discipline-date, draft-account-ux, finance-inputs, finance-ux, finance-queries, navigation-study-ux, pwa-ux, ui.
- Kegagalan request, validasi, isolasi akun dan kondisi bersamaan diuji dengan mock. Tidak memaksa kegagalan atau menyimpan data percobaan ke akun nyata.
- Browser workspace/build produksi: draft Diary pulih setelah Diary–Habits–Diary; Cancel akun memulihkan nama; tema terang bertahan setelah reload; pemilih wallet menerima fokus keyboard; akun kosong memiliki CTA setup.
- Mobile 390×844: tidak ada overflow halaman; kedua form harian di layar awal; dialog Semua fokus ke Close, Escape kembali ke pemicu; jadwal enam kartu tanpa tabel lebar.
- Tablet 900×900: sidebar 224 px, label terlihat, tombol ekspansi tersedia, tanpa overflow halaman. Desktop 1440×900 diperiksa.

## Batas yang disengaja

- Riwayat completion/streak belum disimpan. Dashboard tidak lagi mengklaim riwayat tersebut.
- Draft Diary satu draft per akun/tab, maksimum 24 jam; tidak sinkron lintas perangkat. Form finance mempertahankan isian saat gagal simpan, bukan setelah pengguna meninggalkan halaman.
- Jadwal tetap snapshot semester; RPS belum memiliki dokumen atau progress tracker yang valid.
- Life OS membutuhkan internet untuk data dan penyimpanan; tidak ada antrean simpan offline.
- Target LCP ≤2500 ms, INP ≤200 ms, CLS ≤0,1; JS awal ≤200 KiB gzip +80 KiB/rute; Lighthouse aksesibilitas ≥90/performa ≥80 belum diukur. Tidak mengklaim lulus metrik p75/Lighthouse.
- Perubahan ada pada kode/build lokal. Aplikasi desktop yang sudah terpasang tetap memakai bundle lama sampai installer/release diperbarui.
